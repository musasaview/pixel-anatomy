# pixel-anatomy — ピクセルの中身を覗く

画像のピクセルと、LCD・OLED・CRT・印刷の模式的な構造を拡大して観察するWebGL2の体験型ページです。本文は8言語に対応し、通常の1倍表示では文字と画像を鮮明なDOM表示で読み進められます。

## 起動

Bunを使用します。描画にはWebGL2対応ブラウザーが必要です。

```sh
bun install --frozen-lockfile
bun run dev
```

`http://localhost:5173` を開きます。

| コマンド | 用途 |
| --- | --- |
| `bun run dev` | 開発サーバー |
| `bun run build` | 型チェックと `dist/` への本番ビルド |
| `bun run preview` | ビルド済みページの確認 |

依存関係は `package.json` と `bun.lock` で管理します。`preview` の前には `build` を実行してください。

## ページの構成

ページは、ピクセルと光の導入、ユーザー提供の猫のアクションゲーム画像と猫の拡大図、4種類の表示・印刷方式と11種類の構造例、サブピクセルレンダリングの短い説明、3点のギャラリーの順です。ギャラリーには猫の写真、色相とグレーの見本、幾何学模様を並べています。

RGBの丸い光はゆっくり移動して重なり、細いRGBの線も動きます。拡大すると選択中の表示方式を通して小さな発光素子として見えます。再生と一時停止を切り替えられます。

表示方式の説明では、LCDの液晶とフィルター、OLEDの自発光、CRTの蛍光体、印刷インクによる光の吸収を紹介します。文字比較では同じ輪郭をグレースケールとRGBサブピクセル方式で表示し、それぞれにPIXELとLCDの拡大図を添えています。サンプルの画素はテクスチャの画素へ直接対応し、間に再サンプリングを挟まずに拡大できます。これは方式を説明するための画像で、OSやブラウザーの文字描画を測定・再現するものではありません。

1倍表示の文字と画像はDOMで表示し、RGBの光は記事内のCanvas 2Dで描画します。拡大時はWebGLに切り替えます。PIXEL以外の出力Canvasは最大DPR 1.5、約250万画素に制限し、PIXELは端末のDPRとWebGLのテクスチャ上限に合わせます。拡大中はズームに応じてRGBの動きを遅くし、表示中にだけ描画を続けます。

## 読む・観察する

- **通常のスクロール**：記事を読み進めます
- **Ctrl＋ホイール / トラックパッド**：カーソル位置を中心にズームします
- **ドラッグ**：拡大時に表示位置を動かします
- **タッチ操作**：1本指でスクロール、2本指のピンチで最大2048倍まで拡大・縮小。拡大中は1本指で移動します。スマートフォンの方式一覧は横スクロールでき、詳細な数値は設定内で確認できます
- **ダブルクリック**：拡大します
- **右クリック / Shift＋ダブルクリック**：縮小します
- **`+` / `−`**：ズームします。拡大時の矢印キーで表示位置を動かせます
- **`R` / `0`**：1倍表示に戻ります
- **`Esc`**：設定パネルと操作説明を閉じます

下部の方式メニューから、PIXELと次の11種類の構造を選べます。

| 方式 | 模式的に表す構造 |
| --- | --- |
| PIXEL | 元のピクセルを同じ色の四角として拡大 |
| LCD RGBストライプ | RGB開口、ブラックマトリクス、電極線（初期選択） |
| LCD シェブロン | くの字に折れ曲がるRGB開口 |
| LCD VAマルチドメイン | RGB開口内の電極スリットと領域境界 |
| OLED Diamond PenTile | 菱形の赤・青要素と、より多く配置した緑要素 |
| QD-OLED三角RGB | 三角形に並ぶ赤・緑・青の発光領域 |
| SストライプRGB | 左側に上下配置した赤・緑と、右側の縦長の青 |
| WOLED RWBG | RGBフィルター領域と、フィルターを通さない白色要素 |
| CRTスロット型シャドーマスク | 縦長のRGB蛍光体領域と横向きの橋 |
| CRTシャドーマスク | 千鳥配置のRGB蛍光体ドット |
| CRTアパーチャーグリル | 縦方向の蛍光体ストライプとダンパー線 |
| CMYK印刷 | 網点、紙とインク、減法混色 |

配列や寸法は代表的な模式モデルで、特定製品の実測値ではありません。応答速度や残像、実際の印刷色域は再現しません。

標準の猫写真はRoc0ast3rによる [Red tabby looking down at camera](https://commons.wikimedia.org/wiki/File:Red_tabby_looking_down_at_camera.jpg) です。CC0 1.0で公開された写真をローカル配信します。出典とライセンス情報は [public/images/CREDITS.md](public/images/CREDITS.md) にあります。

「画像を選んで表示」では、選んだ画像をこのブラウザー内で表示します。サーバーへの送信や画像の保存は行いません。「猫の写真に戻す」または再読み込みで標準の写真に戻ります。

## 8言語と構成

日本語・英語・簡体字中国語・韓国語・スペイン語・フランス語・ドイツ語・ポルトガル語に対応しています。言語の自動検出と手動選択を利用できます。

- `src/main.ts`：記事表示、UI、翻訳、方式切替
- `src/content.ts`：記事本文、文字比較、色見本
- `src/education.ts`：表示方式の説明と文字比較の解説
- `src/displayCopy.ts`：方式別の導入、11種類の構造名と説明
- `src/locales.ts`：UIと方式名の翻訳
- `src/labCopy.ts`：標本と画像操作の翻訳
- `src/pixelArt.ts` / `src/pixelCopy.ts`：ゲーム画像の読み込み、猫の拡大図、ピクセルの説明
- `src/textSamples.ts`：グレースケール／サブピクセル文字と拡大比較図
- `src/panelPreviews.ts`：方式別プレビュー生成
- `src/motifs.ts`：色見本と幾何学模様
- `src/panels.ts`：表示方式と模式アイコン
- `src/renderer.ts` / `src/lcdShader.ts`：WebGL描画と表示方式のモデル
- `src/interaction.ts` / `src/viewport.ts`：ズーム、パン、スクロール

フォントファイルは同梱・配信せず、端末のシステムフォントを使用します。

## PIXELモード

コントロール左端のPIXELは、元の色の四角を最近傍サンプリングで拡大します。発光マスク・隙間・光学的な補正は加えません。ゲーム画像は通常表示で画像1pxを画面の物理1pxに対応させます（CSS寸法はdevicePixelRatioで調整）。画面幅に収まらない場合は表示幅を縮めます。拡大時はページキャプチャを経由せず元のビットマップを参照し、輪郭とパレットを保ちます。

## 開発時の確認

`bun run build` と `git diff --check` を実行します。UI変更は既存のPlaywrightキャッシュにある専用Chromiumで、変更に関係する項目を確認してください。

- 等倍・拡大・最大2048倍での表示と、320px幅での重なりやはみ出し
- 方式と8言語の切り替え、画像の読み込み、ブラウザーエラー
- キーボードでの設定操作、ローカル画像の選択と復元

開発方針は [AGENTS.md](AGENTS.md)、描画の仕様・限界と参考資料は [技術資料と確認記録](docs/TECHNICAL_NOTES.md) にまとめています。

## Gitで管理するもの

ソース、翻訳、配信用素材、出典、`bun.lock` を管理します。`dist/`、`node_modules/`、ログ、ブラウザー検証の出力、環境変数、非公開の `_sample_assets/` は除外します。一時的なスクリーンショットや検証スクリプトは `/tmp` に置いてください。

既存の未コミット変更を保持し、コミット前に `git status --short` と差分を確認してください。画像・フォントの利用条件は素材ごとに異なります。
